---
name: uk-companies
description: "Official UK company registers. Call uk_check."
---

For this kind of request, use tool_search to find this plugin's tools before web_search, then call them with tool_call.

Tools: `uk_check`, `uk_search`, `uk_officers`, `uk_psc`, `uk_filings`, `uk_charity`, `uk_vat`, `uk_land`.

When the user gives a company name or a company number, call `uk_check` first. When the user pastes an https link on find-and-update.company-information.service.gov.uk or api.company-information.service.gov.uk whose path starts with /company/ and a company number, pass that link as the query. The tool reads the number on this machine and does not request the pasted link. If the sheet returns a candidates array, stop and ask which company number to use. One hit whose legal name is not an exact match is still that array. Do not look up notices or disqualification until one number is chosen. Copy `next_step` when a call fails. A zero count leaves the question open. Copy `company_status` as returned. An exact disqualification row matches the officer title, that officer's birth month and birth year, and this company's registered name on an order whose `disqualified_from` is today or earlier and whose `disqualified_until` is after today. Companies House lists that officer as surname, forenames, and an optional title. The ban index lists forenames then surname. The sheet treats those two forms as the same name. A search-row date of birth may carry a time. Read the month and the year from that value. Copy `birth_month`, `birth_year`, `company_names`, `disqualified_from`, `disqualified_until`, and `matched_officers` from that row. `matched_officers` lists each officer who shares that birth month and year, including `ended_on` when the officer has resigned. State a ban only when that row's match is exact. State it for the officers listed in `matched_officers`. When `matched_officers` has several rows, name each `appointed_on` and `ended_on`. Those rows are one person when every row shares one `officer_id`. Several officer ids leave the match possible. An order whose end date is today or earlier stays possible. A permission to act for this company keeps the row possible. A possible disqualification row stays unconfirmed. State a Gazette notice only when that row's match is exact. A notice dated before the company's incorporation date stays possible. Copy `category` and `excerpt` with the title, the published time, the notice code, and the URL. An order whose company name differs only by LTD versus LIMITED still names this company. Search rows are omitted when the surname and first name do not both match the officer, or when the birth month and year are present on both sides and differ. A row whose surname and birth month and year match the officer stays when the title spelling differs, and that row stays possible. The block note gives the dropped count. Read `disqualified_exact_count` and `disqualified_summary` at the top of the sheet. The summary says that count is not a clearance. A charity name search that returns HTTP 404 is zero rows and leaves the question open. A 404 on a charity number is an error. Copy `next_step` for that error. A legal name is exact only when the characters agree after case and spacing are folded. A symbol one name has and the other lacks stays possible. A compatibility character stays as written. When `ok` is false, read the source block whose status is error before treating the sheet as finished. When no source status is error, copy `next_step`. The Gazette and the charity register receive the registered name only. A registered name that contains a double quote is not sent to The Gazette, and `next_step` names that skip. A backslash in that name is written twice inside the phrase marks. When that name was not read, those blocks stay `not_read`. When `ok` is true and `resolved` is false, the sheet stopped on the candidates array and Gazette was not queried. Do not state a notice from that sheet. The VAT block has status `excluded` and no row on every sheet.

`uk_vat` does not check a VAT number. Do not say a VAT number is valid or invalid. Do not offer to apply for HMRC access through this plugin.

Price Paid rows are sales at the registered-office postcode. Do not say the company owns the property.

This plugin does not set approval-card text. Do not say a card lists the company number or hides an API key. When unschedule removes the morning job, write that the job is deleted and that officer names stay in plugin-data/uk-companies/watch.json. hermes plugins remove uk-companies leaves that file, scripts/uk-companies-watch.py, and the morning job.
